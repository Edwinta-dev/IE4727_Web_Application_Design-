Status: implemented · Issue: #214 · Date: 2026-10-28

## In short

Print styles hide the appointment page chrome and tables only when a completed consultation summary is rendered.

## How it works

The print hide selectors use `body:has(.medical-slip)` as their ancestor condition. Without a rendered slip, the appointment sections keep their normal print display. With a slip, the existing summary-only print layout applies.

## Main design choice

Use `body:has(.medical-slip)` rather than adding a PHP class to `<main>`. The stylesheet can scope the existing selectors directly without changing page markup, and current browser support in the Playwright Chromium target covers `:has()`.

## Traps

The completed appointment query can fail or return no result for an invalid `view`; only the rendered `.medical-slip` should activate print hiding.

## Components

`clinic-base/assets/css/style.css`, `tools/ui/standout-features.test.mjs`, and `tests/test_standout_features.php`.

## Breaks or needs follow-up

None.

## Problem and constraints

The previous print block hid appointment tables on all pages using the shared stylesheet. Keep the 1.5 cm page margin and black-on-white summary, stay within the existing page budget, and avoid unrelated refactors.

## Alternatives considered

Add a conditional class to `<main>` in `patient/home.php`; rejected because the existing summary element already provides a precise condition and avoids changing page markup.

## Trade-offs

The CSS `:has()` selector requires a modern browser; it is supported by the Chromium version used by the UI check.

## Key parameters

`@page` margin remains `1.5cm`. Print hiding is conditioned on `.medical-slip` under `body`.

## Assumptions

The consultation summary is emitted only when a valid completed visit is open, as implemented by the existing patient page.

## Edge cases

An invalid or unauthorized `view` without a summary must leave the appointment tables visible in print.

## Not verified

None.

## Changes outside the scope

None.

## How it was verified

The Playwright check emulates print on the normal appointment page and with `?view=2`, asserting the tables remain visible in the former and hidden in the latter. The PHP feature test checks scoped selectors and retained print styling.

## To change this

Update the selector condition if the consultation summary container changes, and keep both print states covered in the browser check.

## Rollback

Revert this decision and the three scoped code/test changes to restore the unscoped print behavior.
